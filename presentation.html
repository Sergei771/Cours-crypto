3. Mécanismes de Sécurité Clés (5-6 min)

Les choix techniques majeurs (réponse aux exigences techniques du CDC) :

  • Hachage Mots de Passe: Argon2id
    • Exigence CDC : Hachage sécurisé.
    • Pourquoi ? Standard moderne, résistance GPU/ASIC. [Voir Comparaison vs bcrypt...]
    • # Server: routes/session/login.py (Vérification)
try:
    ph.verify(user.password, password) # 'user.password' est le hash Argon2id stocké
    # ... Success
except exceptions.VerifyMismatchError:
    # ... Failure

      Vérifie le mot de passe fourni contre le hash sécurisé stocké. Échoue en toute sécurité si différent.

    • (Réf Code Complet: Server PasswordHasher)
  • Gestion de Session: JWT (JSON Web Tokens)
    • Exigence CDC : Authentification robuste, anti-usurpation.
    • Pourquoi ? Stateless, scalabilité, infos user embarquées. [Voir Justification]
    • # Server: routes/session/login.py (Création)
token = jwt.encode({
        "user_id": user.id,
        "is_admin": user.is_admin,
        "exp": datetime.now(timezone.utc) + timedelta(hours=1) # Expiration 1h
    }, JWT_SECRET, algorithm="HS256")

      Crée un token signé contenant ID, rôle admin, et une date d'expiration.

    • (Réf Code Complet: Client `sessionStorage`, Server `@require_jwt`)
  • Gestion Clé Secrète JWT :
    • Réponse au CDC ("obfuscation") : Bonne pratique moderne = stockage sécurisé via variable d'environnement.
    • # Server: app.py / db.py
SECRET_KEY = os.getenv("SECRET_KEY")
JWT_SECRET = os.getenv("SECRET_KEY") # Utilisée pour signer/vérifier JWT

      La clé secrète n'est pas dans le code, mais chargée depuis l'environnement serveur.

    • [Bonnes Pratiques]
  • Protection/Intégrité Photos & Stéganographie :
    • Exigence CDC (double) : Intégrité photo ET utilisation stégano.
    • Intégrité : Stockage BLOB limite certains risques. Hachage serait une amélioration future. [Justification BLOB]
    • Utilisation Stégano : Fonction `test_steno` implémentée (canal admin ?). [Détails Concept] (Réf Code: Client LoginForm appelant test_steno)

Anticipation et prochaines étapes pour renforcer encore la sécurité :
